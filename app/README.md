# RetailSphere - Enterprise E-Commerce Platform

## Overview

RetailSphere is an enterprise-grade e-commerce platform built to demonstrate modern DevOps and Cloud Engineering practices.

The project covers the complete software delivery lifecycle including:

* Spring Boot Application Development
* MySQL Database Integration
* JWT Authentication & Authorization
* Terraform Infrastructure as Code
* Ansible Configuration Management
* Docker Containerization
* Jenkins CI/CD
* SonarQube Code Quality
* Nexus Artifact Management
* Kubernetes Deployment
* AWS Cloud Infrastructure
